# Botiga Copilot

## Stack
- Backend: Node.js amb Express i SQLite (mòdul `node:sqlite`), amb mòduls ES (`import`/`export`).
- Frontend: HTML, CSS i JavaScript sense frameworks.
- Tests: runner integrat de Node.js (`node:test` i `node:assert/strict`).

## Convencions
- Noms de variables, funcions i missatges en català, en camelCase.
- Creacio de rames noves per cada tipus, si es una feature tindra la seguente estructura: feature/"nom de la feature" si es un fix tendra la nomenclatura fix/descripciobreudeelfix+data.
- Procuraras mantenir una arquitectura clara y escalable (DENO)
